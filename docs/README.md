
# TrueCost

Understand the true cost of your loan before you borrow.

## About the Project

TrueCost is an educational application that helps users understand loan costs, evaluate affordability, and identify warning signs in suspicious loan offers.

## Features

- Loan EMI calculation
- Total interest calculation
- Processing fee and GST analysis
- Hidden cost analysis
- Monthly affordability checking
- Loan verdict
- Scam message detection
- AI-powered explanations

## Technology Stack

- React
- Vite
- JavaScript
- Tailwind CSS v4
- Firebase AI Logic / Vercel Functions

## Installation

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd truecost
npm install
```

## Environment Configuration

Create a `.env` file using `.env.example` as a reference. Never commit secrets.

## Run Locally

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
